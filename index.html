TASK 1 · ASSIGNMENT 1
MySQL · SQL

Schema Design & ER Modelling

Designed the complete relational database from scratch — ER diagram, normalised schema, check constraints, and sample data across 9 tables.

  • Full ER diagram covering all entities, relationships, cardinalities
  • Normalised MySQL schema with 9 tables, all PKs, FKs, and cascades
  • Business constraints: FinalAmount check, expiry after manufacture, positive prices
  • Self-referencing Employee hierarchy and nested Product Categories
  • Sample data across all tables for realistic query testing

TASK 2 · ASSIGNMENT 2
Python · Flask

Indexing Engine & Web Application

Built a B+ Tree index engine from scratch in Python, then a full Flask REST API with JWT auth, RBAC, and a billing counter UI on top of MySQL.

  • Module A — B+ Tree engine: insert, delete, range query, Graphviz tree diagrams, perf benchmarks vs O(n) baseline
  • Module B — Flask REST API: JWT auth (HS256), Admin vs User RBAC, full CRUD for all entities
  • Member portfolio page + billing counter with cart
  • Security audit log — every API action recorded
  • SQL index benchmarking Jupyter notebook
FlaskPyJWTbcryptB+ TreeRBACJupyter
TASK 3 · ASSIGNMENT 3
WAL · 2PL · ACID

Transactions, WAL, and ACID

Added full transaction support to the B+ Tree engine with WAL and 2PL. Verified all four ACID properties with a comprehensive test suite including Locust load tests.

  • WALLogger — appends every op to wal.log before touching the B+ Tree
  • LockManager — S/X table locks, 2-phase locking, configurable timeout
  • SnapshotManager — per-transaction snapshots for rollback
  • ACID test suite: concurrent users, race conditions, failure simulation, Locust load tests

TASK 4 · LATEST ✦
Sharding · Distributed

Horizontal Database Sharding

Sharded Member, Sale, and SaleItem across 3 remote MySQL Docker nodes using MD5 hash-based routing with co-location and graceful degradation.

shard_id = int(MD5(member_id)[:8], 16) % 3
  • Sale + SaleItem co-located with Member — zero cross-shard joins
  • 6 automated tests: routing, single-shard lookup, insert, range fan-out, distribution, no duplication
  • Graceful degradation: unreachable shard → degraded: true
  • Migration script + phpMyAdmin on each of 3 Docker nodes
